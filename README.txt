IMPORTANT:
Google Sites does not provide a feature to import an entire HTML website as a ready-made site.
This package is suitable for publishing as a static website, for example with GitHub Pages.

Before publishing:
1. Open index.html and replace the sample LinkedIn and Facebook links with your exact profile URLs.
2. Review the wording and professional titles so they accurately reflect your current status.
3. Publish the site publicly.
4. After it is live, add the exact website URL in Google Search Console and request indexing.
Indexing and ranking are not guaranteed.
